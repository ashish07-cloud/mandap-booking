# Mandap Booking System

![Project Banner](https://via.placeholder.com/1200x400?text=Mandap+Booking+System) <!-- Replace with actual banner -->

A modern web application for booking traditional Indian wedding mandaps (pandals) with real-time availability tracking and management system.

## 🌟 Features
- **User Registration & Authentication**
  - Secure login system with email verification
  - Profile management with booking history
- **Mandap Search & Filtering**
  - Location-based search with map integration
  - Filter by capacity, amenities, and price range
- **Booking Management**
  - Real-time availability calendar
  - Multi-step booking process with confirmation
- **Admin Dashboard**
  - Mandap inventory management
  - Booking approvals and customer support


## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python (Flask/Django)
- **Database**: SQLite/PostgreSQL
- **DevOps**: Git, GitHub Actions


## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip package manager
- Modern web browser

### Installation
```bash
# Clone repository
git clone https://github.com/ashish07-cloud/mandap-booking.git

# Install dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env

# Run application
python app.py
```

## 📖 Usage Guide
1. **Registration**: Create a new account
2. **Search**: Find mandaps using filters
3. **Book**: Select dates and confirm booking
4. **Payment**: Complete secure transaction
5. **Manage**: View/Cancel bookings in dashboard
